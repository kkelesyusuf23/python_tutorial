## 🛠️ Technology Stack
Throughout these 51 projects, the following modern tech stack has been extensively utilized:
- **Core:** Python 3.9+, AsyncIO, Multithreading, Subprocess (Agentic AI)
- **Web Frameworks:** FastAPI, Flask
- **Databases:** SQLite, PostgreSQL, JSON Document Stores
- **Real-Time / Networks:** WebSockets, WebRTC, TCP/IP, Load Balancing, Edge Caching
- **Artificial Intelligence:** OpenAI API, HuggingFace Transformers, LLM Tool Calling (Agentic AI), NLP Pipeline
- **Computer Vision (AR):** OpenCV, Google MediaPipe (Face Mesh, Hand Tracking, 3D Physics)
- **Web3 / Blockchain:** Web3.py, Custom Blockchain Architecture, SHA-256 Cryptography
- **Other:** BeautifulSoup4 (Web Scraping), JWT Authentication, OAuth2, GraphQL, Celery (Background Tasks)

## 🚀 How to Run
Each project is encapsulated within its respective directory. To run any project:
1. Navigate to the project folder: `cd <project_name>`
2. Install dependencies (if any): `pip install -r requirements.txt` (or refer to the project's source code for specific libs like `opencv-python`, `fastapi`, etc.)
3. Run the main entry file: `python3 main.py`

*Note: Some AI and Web3 projects may require API keys (e.g., OpenAI API) or specific Node RPC URLs configured as environment variables.*
